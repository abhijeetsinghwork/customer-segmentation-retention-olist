# Customer Segmentation, Churn Prediction & CLV Modeling

### End-to-End Customer Analytics Project (Olist E-commerce Dataset)

## Project Overview

Customer retention is one of the most important drivers of revenue in e-commerce.  
Understanding **which customers are valuable, which customers are at risk of leaving, and where to invest retention efforts** can significantly improve business outcomes.

This project builds an **end-to-end customer analytics pipeline** using the Brazilian Olist e-commerce dataset.

The analysis progresses from **descriptive analytics → predictive modeling → business strategy**, demonstrating how data science can support real customer retention decisions.

The project includes:

- Customer feature engineering
- RFM customer segmentation
- Churn prediction using machine learning
- Customer Lifetime Value (CLV) estimation
- Customer value prioritization
- Retention strategy simulation

---

# Dataset

This project uses the **Olist Brazilian E-commerce Public Dataset**.

The dataset contains real transactions from a Brazilian marketplace between **2016 and 2018**, including:

- customers
- orders
- order items
- payments
- reviews
- products
- geolocation

Dataset Source:  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

---

# Business Problem

For an e-commerce business, several key questions are critical:

1. Which customers are the most valuable?
2. Which customers are at risk of churn?
3. How should retention budgets be allocated?
4. Which customer segments require different strategies?

This project answers those questions by combining **customer segmentation, churn modeling, and lifetime value estimation**.

# Analytical Workflow

The project follows a structured customer analytics pipeline.

---

## 1. Data Understanding

Exploration of the Olist dataset to understand the structure and relationships between:

- customers
- orders
- payments
- products
- reviews

Key tasks:

- inspecting data quality
- validating primary keys
- identifying join relationships

`01_data_understanding.ipynb`

## 2. Customer Base Table

Created a **customer-level feature table** containing behavioral metrics such as:

- recency
- order frequency
- total spend
- average order value
- tenure
- purchase activity metrics

Notebook:  
`02_customer_base_table.ipynb`

Output:
data/processed/customer_base.csv

---

## 3. RFM Customer Segmentation

Customers were segmented using **RFM analysis**:

- **Recency** – how recently a customer purchased
- **Frequency** – how often they purchase
- **Monetary** – how much they spend

Example segments include:

- Champions
- Loyal Customers
- High Value At Risk
- New Customers
- Hibernating

Notebook:  
`03_rfm_segmentation.ipynb`

---

## 4. Churn Prediction

A machine learning model was built to predict whether a customer will **churn within 90 days**.

Features used include:

- recency
- purchase frequency
- monetary value
- purchase timing behavior

Models evaluated:

- Logistic Regression
- Random Forest

Outputs:

- churn probability
- churn risk bands
- scored customer table

Notebook:  
`04_churn_model.ipynb`

Output:
data/processed/customer_churn_scores.csv

---

## 5. Customer Lifetime Value (CLV)

Customer Lifetime Value was estimated using probabilistic models:

- **BG/NBD model** – predicts future purchase frequency
- **Gamma-Gamma model** – predicts expected transaction value

These models estimate the **expected future revenue generated by each customer**.

Notebook:  
`05_clv_model.ipynb`

Output:
data/processed/customer_clv_scores.csv

---

# Customer Value Matrix

The analysis produces a **CLV × Churn Risk matrix**, widely used in customer strategy.

| CLV      | Churn Risk | Strategy                      |
| -------- | ---------- | ----------------------------- |
| High CLV | High Risk  | Immediate retention campaigns |
| High CLV | Low Risk   | Loyalty programs / upsell     |
| Low CLV  | High Risk  | Low-cost retention            |
| Low CLV  | Low Risk   | Automated engagement          |

---

# Retention ROI Simulation

To demonstrate business decision-making, the project includes a **retention campaign simulation**.

Expected retained value is estimated as:
Expected Retained Value = CLV × Churn Probability × Intervention Success Rate
Expected ROI = Expected Retained Value − Campaign Cost

Customers are ranked by **expected retention ROI**, allowing businesses to prioritize intervention.
