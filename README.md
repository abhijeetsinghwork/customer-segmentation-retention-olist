# Customer Segmentation & Retention (Olist Dataset)

## Project Overview

This project explores customer behavior in a real-world e-commerce dataset to:

- segment customers using RFM analysis
- predict churn risk
- estimate customer lifetime value (CLV)
- recommend targeted retention strategies

## Dataset

Brazilian e-commerce public dataset by Olist (2016–2018).

## Tech Stack

- Python
- pandas, numpy, scikit-learn
- matplotlib, seaborn
- Jupyter Notebook
- Streamlit (deployment)
